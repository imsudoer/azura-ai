# azura-ai — Roadmap

Tracked outside of git issues so the assistant always has it in context.

## Near term

- [ ] **Tests** (task-16): unit + humanity + activity + social + integration with kurigram mocks. The test plan is sketched in `PROJECT_CONTEXT.md`.
- [ ] **Vision-input** (`media_tools.note_media`): use a vision-capable model on incoming photos to extract descriptions, feeding the short-term memory.
- [ ] **Sticker thumbnail download** in `stickers_collector` (so the LLM tagger sees a tiny image, not just `emoji + set_name`).
- [ ] **Operator extensions**: `dump <chat_id>` to print recent chat memory; `opinion <user_id>` to inspect; `reload_personality` (rare, requires both lock files to be regenerated by operator command).
- [ ] **Backoff on repeated read_no_reply**: if persona ignores the same chat 5x in a row, write a journal note about why (the chat got boring / annoying).

## Mid term

- [ ] **Voice support**
  - Incoming voice notes → STT (`pplx` / external) → text in short-term memory.
  - Outgoing voice: TTS via OnlySq audio endpoints if/when available; otherwise off-platform provider.
  - Toggle controlled by persona trait (e.g. comfort with voice messages).
- [ ] **Vision generation**: when the persona "wants to send a selfie" — generate via OnlySq image endpoint, send as photo with a believable caption.
- [ ] **Reactions**: thumbs/heart/laugh reactions on incoming messages, decided by mood + opinion (not always a text reply).
- [ ] **Better translator act**: when addressed in an unknown language, simulate "I used a translator" — slightly stilted phrasing + a small extra delay; never claim native fluency.

## Long term

- [ ] **Multi-account**: same code, multiple persona JSONs, isolated DBs and sessions per account.
- [ ] **Memory export/import**: dump `state.db` slices (e.g. one chat, one user) to a portable JSON; re-import into a fresh DB.
- [ ] **Web UI for operator** (read-only): timeline of journal + mood graph + presence chart.
- [ ] **Cluster mode**: shared LLM cache + per-account workers, single sqlite-per-account but a shared embed cache.
- [ ] **Persona ageing**: a slow drift in traits over months (small Gaussian per month, capped), to model life-stage changes. Kept disabled by default since it breaks immutability — opt-in via env flag.
- [ ] **Periodic self-rewrite**: a quarterly "I journaled all this; here's what I learned about myself" pass that adds, but never replaces, persona notes.

## Quality / DX

- [ ] **`alembic` migrations** instead of `Base.metadata.create_all` once we have any persistence to migrate.
- [ ] **Strict type-check** (`mypy` config, baseline of zero new errors).
- [ ] **Pre-commit** with ruff format + lint.
- [ ] **Observability**: optional Prometheus exporter exposing tool calls/sec, attention passes, mood, presence.
